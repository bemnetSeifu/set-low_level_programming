# 0x03. C - Debugging

## Description
This project is part of the low-level programming curriculum. It covers
debugging: testing code with different main files, finding the cause of
wrong output or infinite loops, and fixing it.

## Requirements
- Ubuntu 20.04 LTS
- gcc with the flags -Wall -Werror -Wextra -pedantic -std=gnu89
- Betty coding style

## Files
| File | Description |
|------|-------------|
| main.h | Header file with all function prototypes |
| 0-main.c | Tests positive_or_negative() with the value 0 |
| 1-main.c | Main file with the infinite loop commented out |
| 2-largest_number.c | Fixed function that returns the largest of 3 numbers |
| 3-print_remaining_days.c | Fixed function that prints the day of the year and remaining days, handling leap years |
