# 0x04. C - More functions, more nested loops

## Description
This project is part of the low-level programming curriculum. It covers
functions, nested loops, and printing shapes and number sequences using
only _putchar.

## Requirements
- Ubuntu 20.04 LTS
- gcc with the flags -Wall -Werror -Wextra -pedantic -std=gnu89
- Betty coding style
- Only _putchar is used for output (except 9-fizz_buzz.c)

## Files
| File | Description |
|------|-------------|
| main.h | Header file with all function prototypes |
| 0-isupper.c | Checks for an uppercase character |
| 1-isdigit.c | Checks for a digit (0 through 9) |
| 2-mul.c | Multiplies two integers |
| 3-print_numbers.c | Prints the numbers from 0 to 9 |
| 4-print_most_numbers.c | Prints the numbers from 0 to 9, except 2 and 4 |
| 5-more_numbers.c | Prints the numbers from 0 to 14, ten times |
| 6-print_line.c | Draws a straight line with _ |
| 7-print_diagonal.c | Draws a diagonal line with \ |
| 8-print_square.c | Prints a square with # |
| 9-fizz_buzz.c | Prints 1 to 100 with Fizz, Buzz and FizzBuzz |
| 10-print_triangle.c | Prints a right-aligned triangle with # |
